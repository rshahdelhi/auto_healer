Auto Healer Control Plane

Turn monitoring signals into controlled recovery decisions.

Auto Healer accepts alerts from Dynatrace, Splunk, Phoenix, ADFS, and other monitoring systems, stores each event by project and component, and gives operations teams a policy-driven interface for scale and shutdown decisions.

Monitoring Event Intake

Receive HTTP POST events from monitoring systems and preserve the full provider payload while normalizing project, component, source, severity, title, and message fields.

Mock Scenario Console

Generate test events for Dynatrace, Splunk, Phoenix, ADFS error surge, capacity scale up, capacity scale down, and off-hours stop workflows.

Application Rules

Define min/max replicas, scale thresholds, holiday shutdowns, and off-hours stop windows for each project and component.

04

Endpoint Configuration

Configure the Auto Healer endpoint and ADFS authentication inputs: client ID, server ID, username, and password status.

05

Immutable Audit Trail

Record policy and endpoint configuration changes in SQLite with database triggers that reject updates and deletes.

SRE Postmortems

Manage blameless postmortems and RCA records with incident impact, root cause, corrective actions, lessons learned, status, and owner.

API Documentation
